# Kebitsamang Raleche Portfolio
Free static portfolio for GitHub Pages.

## Publish
1. Create a public GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder.
3. GitHub: Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` -> `/ (root)` -> Save.
4. Visit `https://YOURUSERNAME.github.io`.

GitHub Pages supports personal sites on GitHub Free public repositories. Changes can take several minutes to publish.
